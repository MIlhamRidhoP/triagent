# jin-2025: Survei LLM untuk deteksi kerentanan dalam analisis kode statis

Sumber: Jin, S. (Meituan, Shanghai). "Large Language Models for Vulnerability Detection in Static Code Analysis: A Survey". 2025 8th ICAIBD, DOI 10.1109/ICAIBD64986.2025.11082007 (halaman IEEE sekitar 473 sampai 479).
Status verifikasi: dicek ke PDF pada 2026-10-26
Jenis: paper venue (konferensi), survei satu penulis

## Klaim utama dan metode
Survei yang mengelompokkan adaptasi LLM untuk deteksi kerentanan statis menjadi lima pendekatan: Base Application, Static Analysis Augmentation, Knowledge Enhancement, Fine-tuning Based, Hybrid Feature Fusion. Ditambah perbandingan terstandar pada Devign dan Big-Vul. Sebagian besar isinya merangkum paper lain.

## Angka aman dikutip
- Lima kategori pendekatan, abstrak (PDF hlm. 1) dan kesimpulan VII (PDF hlm. 6).
- Definisi Static Analysis Augmentation: menggabungkan alat analisis statis tradisional dengan LLM untuk menambah kemampuan deteksi dan mengurangi false positive. Bagian IV.B (PDF hlm. 3, halaman IEEE 475). Koreksi seed: ini bagian IV.B, bukan III.B.
- Pada Big-Vul, GRACE menaikkan F1 GPT-4.0 dari 20,66% menjadi 35,50% (Bagian V, PDF hlm. 5). Kutip hanya sebagai "dilaporkan oleh survei Jin", bukan sebagai hasil primer.

## Angka tidak aman atau jangan dikutip
- Pernyataan bahwa IRIS menurunkan false positive rate sebesar 5% (IV.B): ringkasan sekunder, tidak sesuai dengan cara catatan iris-2025 melaporkan hasil. Rujuk iris-2025, bukan survei ini.
- Angka Devign dan Big-Vul bersumber dari studi lain dengan pengaturan berbeda, dan data tingkat fungsi, bukan alert SAST di CI/CD. Jangan disejajarkan dengan hasil triagent.

## Batasan dan konflik kepentingan
Survei satu penulis, tujuh halaman, metode pencarian literatur tidak diuraikan. Afiliasi industri (Meituan), tidak ada konflik yang dinyatakan. Pelabelan "hybrid" di sini berarti fusi fitur model, berbeda dari hibrida SAST plus LLM.

## Implikasi desain untuk triagent
Memberi kosakata taksonomi (Static Analysis Augmentation) untuk memposisikan triagent: LLM dipasang di atas keluaran SAST. Dipakai hanya sebagai rujukan taksonomi. Rujukan: D-12 di docs/DESIGN-TRACE.md.
