# Folder PDF literatur

Taruh PDF di sini. Seluruh isi folder ini diabaikan git (kecuali README ini), jadi PDF tidak pernah masuk repo publik. Alasannya hak cipta dan ukuran.

Penamaan: `<key>.pdf`, kunci mengikuti `docs/literature/INDEX.md` (contoh: `iris-2025.pdf`).

Agent tidak membaca PDF secara rutin. Fase 0 membuat catatan ringkas di `docs/literature/notes/` dan semua fase berikutnya bekerja dari catatan itu. PDF hanya dibuka saat menulis atau memverifikasi catatan.

Alat pencarian kadang melewati berkas yang diabaikan git, jadi bila agent perlu membuka PDF, berikan path-nya secara eksplisit.
